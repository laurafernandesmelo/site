Conceito de Software

O que é um software?

Software é todo programa que roda em um dispositivo eletrônico, como um computador ou celular. Ele diz ao hardware o que fazer e como se comportar. Sem software, o hardware não tem utilidade prática. Exemplos: navegador de internet, editor de texto, jogos, sistema operacional.

O que é um sistema operacional?

É o software mais importante de um computador. Ele faz a ponte entre o hardware e os outros programas. Sem ele, o computador não funcionaria. Funções: gerenciar arquivos, memória, dispositivos e programas. Exemplos: Windows, macOS, Linux, Android, iOS.

O que é uma licença de software?

É um contrato legal que define como o software pode ser usado. Ele protege os direitos do desenvolvedor e impõe regras para o usuário. Tipos comuns: licença gratuita, paga, livre, por assinatura, etc

O que é um Software Licenciado?

É um software que exige uma licença para ser usado legalmente. O usuário deve aceitar os termos e, às vezes, pagar por isso. Exemplos: Microsoft Office, Adobe Photoshop, antivírus pagos.

O que é um Software livre?

É um software que dá liberdade ao usuário para: - Usar o programa como quiser; - Estudar o código-fonte; - Modificar o código; - Compartilhar com outras pessoas. Exemplos: Linux, LibreOffice, GIMP.

O que é um Software Proprietário?

É o oposto do software livre. O usuário não tem acesso ao código-fonte e só pode usar o programa de acordo com as regras do criador. Exemplos: Windows, macOS, Microsoft Office.

O que é um software de Sistema?

São programas que cuidam do funcionamento básico do computador. Eles trabalham "por trás das cortinas", ajudando o hardware a conversar com os programas. Exemplos: drivers, BIOS, sistemas operacionais.

O que é um software Aplicativo?

É o software que você usa para fazer tarefas no dia a dia: escrever textos, ver vídeos, acessar a internet, jogar, etc. Exemplos: Word, Chrome, Spotify, WhatsApp.

O que é um software de Programação?

São ferramentas feitas para criar outros softwares. Elas ajudam programadores a escrever, testar e depurar códigos. Exemplos: Visual Studio Code, Eclipse, compiladores, editores de código.

O que é um software de diagnóstico de software ?

É usado para encontrar erros e problemas em programas instalados no computador. Ele analisa o funcionamento do software e pode sugerir ou aplicar correções. Exemplos: CCleaner, ferramentas de verificação de integridade do Windows.
